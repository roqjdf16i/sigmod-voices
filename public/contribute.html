Privacy policy

What this website collects

The application stores your text, the optional fields you choose, a posting timestamp, post status, a chosen nickname, a hashed anonymous browser key, and a hashed deletion key. It does not store IP addresses, browser fingerprints, real names, or email fields. A random key is saved in this browser to keep your nickname consistent. The same nickname connects your posts and replies; it does not verify a person. Clearing site data or switching browsers requires a new nickname choice and removes access to browser-based deletion. Ownership is checked using the private browser key, never the displayed name. There are no analytics, third-party fonts, or embedded trackers.

Source code on GitHub

The website source code is publicly available on GitHub ↗. The repository does not contain the live database, private browser keys, or deployment credentials.

About your nickname

Choose a unique nickname from 1,000 names. It stays the same across the site and becomes fixed when you send your first post or reply. Keep your browser data to manage your contributions, or save deletion receipts as a backup.

Posting and removal

Posts and replies appear immediately. Avoid identifying details, personal attacks, and spam. You can delete your own content using this browser or a saved deletion receipt.

Withdraw a contribution

Use your receipt to remove a post or reply from this site's active database. Removing a post also removes all its replies.
